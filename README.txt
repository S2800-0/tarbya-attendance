تسجيل الحضور بالـ QR — كلية التربية – جامعة المنوفية
=====================================

كيف يعمل:
- الطالب: يفتح الرابط ← "بطاقة الطالب" ← يكتب اسمه ورقمه الجامعي وفرقته مرة واحدة ← يظهر له رمز QR يتجدد كل ٥ ثوانٍ.
- عضو هيئة التدريس: يفتح نفس الرابط ← "تسجيل الحضور" ← يكتب اسم المحاضرة ← يشغّل الكاميرا ويمسح رموز الطلاب ← "تنزيل ملف Excel".
- تنبيهات تلقائية: الطالب المسجّل مرتين، رمز قديم (لقطة شاشة)، طالبان من نفس الهاتف.
- يعمل بدون إنترنت بعد أول فتح، ويمكن إضافته للشاشة الرئيسية كتطبيق.

تخصيص (في أعلى ملف index.html داخل CONFIG):
- university: اسم الجامعة يظهر تحت اسم الكلية.
- years: الفرق المتاحة (حالياً 1 إلى 4).
- الشعار: ضع صورة باسم logo.png بجانب index.html.
